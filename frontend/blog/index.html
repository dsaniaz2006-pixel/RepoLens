Engineering note · RAG

Why repository revisions matter

RepoLens groups indexed chunks by repository and commit revision so an answer can point to the version of the source that was actually analyzed. When the branch advances, the old index may no longer represent current source.

For this reason the workspace asks you to refresh the RAG index when the revision changes. A useful citation should identify a file and source lines on the pinned commit, not simply link to a moving branch.

Engineering note · Reliability

How to read an AI-assisted report

RepoLens selects public files, runs Gemini analysis on bounded source context, and marks gaps when sufficient evidence is missing. This can miss important code paths and does not verify every generated claim.

Use source citations as places to check, not as automatic proof. The public gallery labels source snapshots separately from independently reviewed architecture reports.
