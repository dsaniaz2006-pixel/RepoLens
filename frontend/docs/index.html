Documentation / setup

Start from source.

Set up locally, connect your AI provider, then analyze public GitHub repositories. These instructions follow the included README and current project commands.

01 / Install

Python 3.11+, Node.js 18+ and permission to analyze public repository source are required.

From the project root · macOS

python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cd frontend && npm ci && cd ..
cp .env.example .env

Fill in your own secrets in .env; never commit that file. Existing Neon, OAuth and Gemini settings must be preserved across upgrades.

02 / Start & sign in

The launcher starts the FastAPI backend and Vite dashboard. Sign in with your configured Google or GitHub OAuth app.

node start.mjs --https

Open the dashboard ↗ · Log in ↗

With local mkcert setup, development runs at https://127.0.0.1:5173 using node start.mjs --https. If ports 8000 or 5173 are occupied, stop the old RepoLens server first.

03 / Analyze via CLI

Indexes are revision-specific. Build a RAG index before asking questions and refresh when the repository changes.

python -m backend.cli.main https://github.com/pallets/flask
python -m backend.cli.main https://github.com/pallets/flask --index
python -m backend.cli.main https://github.com/pallets/flask --ask "Where is routing handled?"

CLI calls to Gemini use your configured provider and may consume API quota.

04 / API & troubleshooting

For authenticated API access use your browser session or an API token created under Settings. See the project README for all supported endpoints.

Common issues

  • Port already in use: inspect lsof -nP -iTCP:8000 -iTCP:5173 -sTCP:LISTEN.
  • Index missing: build or refresh for the currently pinned revision.
  • Daily allowance reached: see AI Usage in Home or Settings; quotas reset at 00:00 UTC.
  • Database upgrade: run python -m backend.database.schema_migrations verify from the project root.

For the private interactive FastAPI API reference, use /docs while signed in; this public documentation page is /docs/.
